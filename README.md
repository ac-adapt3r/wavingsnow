# Waving Snow
A really small mod that makes snow wave with the waving node below it, (e.g. leaves, needles) if you have waving enabled in settings.
## Can I install it on an already existing world?
Yes, you can. The snow on top of waving nodes will automatically start waving. Though, if you will try removing the mod, the snow will show as unknown nodes, which can be fixed by writing an LBM.
